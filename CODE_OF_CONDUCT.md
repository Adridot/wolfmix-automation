# Code of conduct

This is a small research project. The rules are short because the situations
are few.

## Expected

- **Argue with evidence.** Disagreement about what a byte means is the point of
  this repository. Bring the file, the diff, the capture — not volume.
- **Be precise about uncertainty.** Saying "I think, but I have not measured
  it" is welcome and costs you nothing here.
- **Assume competence.** People arrive with different halves of the problem:
  some know lighting, some know binary formats, few know both.

## Not accepted

- Personal attacks, harassment, or discriminatory language of any kind.
- Publishing someone else's private information — including a project file that
  carries a venue's patch, or a person's data lifted from a corpus.
- Deliberately wasting maintainer time: fabricated results, claims presented as
  measured when they are not, or output pasted from a model without checking it
  against a real file.

## Enforcement

Report anything covered above through GitHub's private vulnerability reporting
on this repository, or by opening an issue if it is already public. Reports are
handled by the maintainer, who may edit, hide, or remove contributions and
block accounts. In a project this size that is the whole enforcement mechanism;
it will be used if it has to be.
